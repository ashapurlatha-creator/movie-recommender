# 🎬 Movie Recommendation Engine

## 📝 Project Description
This is a Content-Based Movie Recommendation System built with Python. 
It uses **Natural Language Processing (NLP)** to analyze movie tags and **Cosine Similarity** to suggest movies based on user interest.

## 🚀 How to Run
1. Ensure you have Python installed.
2. Install dependencies:
   ```bash
   pip install pandas scikit-learn
Run the engine:
python recommend.py

## 🛠️ Tech Stack

- Python: Core logic
- Pandas: Data manipulation
- Scikit-Learn: Vectorization and Similarity math
- Pickle: Model serialization

## 📊 Dataset

The project uses the TMDB 5000 Movie Dataset which includes plot summaries, genres, and keywords.
